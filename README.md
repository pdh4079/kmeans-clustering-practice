\# K-Means 군집화 연습 프로젝트 (Heart Disease 데이터)



\## 프로젝트 개요

이 프로젝트는 \*\*K-Means 군집화 알고리즘의 기본 개념과 분석 흐름을 이해하기 위한 연습용 프로젝트\*\*입니다.  

심장 질환 관련 정형 데이터를 활용하여, \*\*정답(label)을 사용하지 않는 비지도 학습 방식\*\*으로 데이터가 어떻게 군집되는지를 확인합니다.



---



\## 사용 데이터

\- Heart Disease Cleveland Dataset

\- 정형(Structured) 데이터

\- 타겟(target) 컬럼은 사용하지 않음



> 본 프로젝트는 예측이 아닌 \*\*군집화 특성 파악\*\*을 목적으로 합니다.



---



\## 분석 방법



\### 1. 변수 선택

\- 해석과 시각화를 고려하여 두 개의 수치형 변수만 사용

&nbsp; - `age` (나이)

&nbsp; - `chol` (콜레스테롤 수치)



👉 변수 수를 최소화하여 \*\*군집 결과를 직관적으로 이해하는 데 집중\*\*했습니다.



---



\### 2. 데이터 전처리

\- K-Means는 거리 기반 알고리즘이므로 변수 간 스케일 차이에 민감함

\- `StandardScaler`를 이용해 데이터 표준화 수행



---



\### 3. 모델링

\- 알고리즘: K-Means

\- 군집 수(k): 2

\- 목적: 데이터가 자연스럽게 두 그룹으로 나뉘는지 관찰



---



\## 결과 요약

\- 나이와 콜레스테롤 수치를 기준으로 서로 다른 특성을 가진 두 개의 군집이 형성됨

\- 본 결과는 \*\*질병 여부를 판단하기 위한 예측 모델이 아닌\*\*, 데이터 구조 탐색 목적의 결과임
